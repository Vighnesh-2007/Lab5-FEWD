# Experiment 5 – Student Admission Form

## Aim
To develop a responsive Student Admission Form using HTML and CSS Grid for desktop, tablet, and mobile devices.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- JavaScript
- Visual Studio Code

## Features
- Student personal information fields
- Email and phone number validation
- Course and qualification selection
- Address field
- Confirmation checkbox
- Responsive design for mobile and desktop
- Success message on form submission

## Project Structure
```text
EXP5-Admission-Form/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click and select Open with Live Server.
4. Fill in the form and click Submit Application.

## Result
Successfully developed a responsive Student Admission Form using HTML, CSS Grid, and JavaScript with basic form validation.

## Note
This is a front-end demonstration. Form details are not stored in a database or sent to a server.
